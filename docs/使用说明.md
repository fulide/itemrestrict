# Item Restrict 1.1.0 使用说明

适用于 **Minecraft 1.21.1 + NeoForge 21.1.x + Java 21**。

**1.1.0 是真正的服务端模组：客户端不需要安装。** 限制保存在原版 `minecraft:custom_data` 里，不注册任何自定义 DataComponent，所以不会出现“服务器发送含有未知键的注册表：itemrestrict:restriction”的登录断开。

> 1.0.0 不能只装服务端。它注册了自定义 `itemrestrict:restriction` 组件，客户端没装模组会在登录阶段断开。请改用 1.1.0，并从客户端删除旧的 1.0.0。

## 安装

只把 `itemrestrict-1.1.0-serveronly.jar` 放进服务器的 `mods` 文件夹。

客户端可选安装同一个 jar：装上会显示 tooltip；不装也能正常进服。

## 核心机制

限制写在物品的 `minecraft:custom_data` 中，键为 `itemrestrict:restriction`：

```snbt
{
  "minecraft:custom_data": {
    "itemrestrict:restriction": {
      allowed_tags: ["vip", "admin"],
      deny_message: "你没有权限使用这件物品。"
    }
  }
}
```

- `allowed_tags` 为空表示“谁都不能用”；
- 没有 `itemrestrict:restriction` 表示“不限制”；
- 物品掉耐久、改名、附魔、修复、复制、掉落、装箱、跨维度、重启后，限制仍在；
- 组件不同，物品不会和普通物品堆叠。

## 命令

需要权限等级 2，默认作用于主手物品。

```text
/itemrestrict add <tag>       添加一个允许 tag
/itemrestrict remove <tag>    移除一个允许 tag
/itemrestrict clear           清除主手物品的限制
/itemrestrict info            查看主手物品的限制
/itemrestrict check           检查自己能否使用主手物品
```

给玩家加 tag：

```text
/tag <玩家> add <tag>
```

示例：

```text
/tag Steve add vip
/itemrestrict add vip
```

Steve 现在可以正常使用主手那件物品；没有 `vip` 的玩家右键时会被取消，并看到 actionbar 提示和“村民拒绝”音效。

## 拦截范围

- 右键空气/直接使用物品：食物、药水、弓、盾、雪球等；
- 右键方块使用物品：锄、铲、桶、打火石、放置方块等；
- 右键实体使用物品：命名牌、拴绳、桶、剪刀等。

**不会**因为主手拿着限制物品就禁止打开箱子/门，因为这属于方块交互，不是“使用主手物品”。如果你希望“拿着限制物品就完全不能和任何方块交互”，需要另外加逻辑。

## 注意

- 命令作用于整个主手堆叠；只想锁一件，先拆成 1 个再执行。
- 限制不会自动传播到所有合成/铁砧产物；如果某个配方需要保留限制，要额外复制 `itemrestrict:restriction` 这个 tag。
- 这是访问控制，不是反作弊。能改物品 NBT 的玩家可以移除 tag。要防篡改，需要服务端 profile 映射 + 权限控制。
- 提示有 10 tick 冷却，防止连续右键刷屏。
- `deny_message` 是普通字符串，不是 JSON 文本组件。

## 构建

源码就是本仓库。进入仓库目录后：

```powershell
.\gradlew.bat build
```

产物：

```text
build/libs/itemrestrict-1.1.0.jar
```

本机环境已配置 `GRADLE_USER_HOME=D:\gradle-home` 和 `init.gradle` 镜像；如果你在别的机器构建，需要能访问 NeoForge Maven 仓库。
